# 정형륜 이력서 챗봇

정형륜의 경력과 프로젝트를 대화형으로 살펴볼 수 있는 정적 웹 이력서입니다.

## 바로 보기

[GitHub Pages에서 이력서 보기](https://hrunj1230.github.io/yuta-resume/)

## 주요 기능

- 플로팅 이력서 챗봇
- 프로젝트·경력·기술 스택·학력 추천 질문
- 데스크톱 및 모바일 반응형 UI
- 키보드 탐색과 모션 감소 설정 지원
- 직접 제작한 도트 캐릭터 인터랙션

## 로컬에서 보기

`index.html`을 브라우저로 열면 별도 빌드 없이 실행됩니다.


## 이력서 버전 관리

이 저장소는 자체적인 이력서 버전 관리 및 편집 모드를 지원합니다.

### 폴더 구조

- `resume.html`: 버전 뷰어 및 편집 모드를 지원하는 클라이언트 UI
- `resumes/versions.json`: 모든 버전 기록을 담고 있는 메타데이터 파일
- `resumes/vX.Y.Z/content.html`: 각 버전별 이력서 본문 HTML 조각
- `resumes/vX.Y.Z/resume.docx`: 각 버전별 다운로드용 Word 파일
- `scripts/`: 로컬 편집 서버 및 CLI 도구 등을 포함한 백엔드 스크립트

### 편집 모드 사용법 (로컬 전용)

1. 로컬 편집 서버를 실행합니다:
   ```sh
   python3 scripts/serve.py
   ```
2. `http://127.0.0.1:8000/resume.html` 에 접속합니다.
3. 상단 도구 막대 우측에 나타나는 **"수정"** 버튼을 클릭하여 본문을 편집합니다.
4. 패널에서 버전 증가 방식과 변경 메모를 입력한 후 **"새 버전으로 저장"**을 클릭합니다.
5. 새 버전이 저장되면 변경 사항을 커밋하고 푸시합니다:
   ```sh
   git add resumes && git commit -m "이력서 업데이트" && git push
   ```

*참고: 공개된 GitHub Pages 사이트에서는 보안상 수정 버튼이 노출되지 않으며 읽기 전용 뷰어로만 동작합니다.*

### CLI 방식

스크립트를 통해 터미널에서도 새 버전을 생성할 수 있습니다:
```sh
python3 scripts/new_version.py --bump minor --note "프로젝트 설명 추가"
```
